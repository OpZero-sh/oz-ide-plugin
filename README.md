# Oz IDE

Inspect a source tree and make a change against the version you actually read. Branches, anchored edits and a merge queue help multiple contributors work on one repository.

[Connect with Claude, ChatGPT, Muse Code, or Grok](PROVIDERS.md)

> “Find the function that formats our report, explain its callers, and propose the smallest change to include the date.”

## Working with Oz IDE

Sign in to the account that owns the Oz IDE repository. Oz IDE receives the repository identifiers, source selections and edits you send it. An edit or merge can change a shared branch.

[Product documentation](https://oz-ide.mcp.opzero.sh/) · [Privacy](https://opzero.sh/privacy) · [Support](https://opzero.sh/support)

```text
/plugin marketplace add OpZero-sh/plugins
```
